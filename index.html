This admin dashboard needs a Supabase backend. To connect it:

  1. Create a Supabase project and run the schema + RLS SQL from the project README.
  2. Create your admin user (Supabase Auth → Users), then insert their user_id into the admins table.
  3. Edit admin/config.js and fill in SUPABASE_URL and SUPABASE_ANON_KEY.
  4. Optionally set TURNSTILE_SITEKEY for CAPTCHA on the public poll.

No secrets are committed — config.js only holds the public anon key. See the README for full setup, Edge Function, and deployment instructions.
